개인정보 처리방침

최종 업데이트: 2024년 11월

1. 개요

Tab Timer("당사", "우리", "저희")는 사용자의 개인정보 보호를 매우 중요하게 생각합니다. 본 개인정보 처리방침은 Tab Timer Chrome 확장 프로그램("확장 프로그램", "서비스")을 사용할 때 수집, 사용, 저장 및 보호되는 정보에 대해 설명합니다.

핵심 원칙: Tab Timer는 모든 데이터를 사용자의 기기에만 로컬로 저장하며, 외부 서버로 데이터를 전송하거나 제3자와 공유하지 않습니다.

2. 수집하는 정보

Tab Timer는 다음과 같은 정보를 수집합니다:

  • 방문한 웹사이트 도메인: 전체 URL이 아닌 도메인 이름만 수집합니다 (예: google.com, github.com)
  • 사용 시간 데이터: 각 웹사이트에서 보낸 시간 (분 단위)
  • 세션 정보: 웹사이트 방문 세션의 시작 및 종료 시간
  • 사용자 설정: 시간 제한 설정, 테마 설정, 언어 설정 등

수집하지 않는 정보:

  • 전체 URL 또는 쿼리 파라미터
  • 개인 식별 정보 (이름, 이메일, 전화번호 등)
  • 웹사이트 콘텐츠 또는 검색어
  • 비밀번호 또는 기타 민감한 정보

3. 정보 사용 목적

수집된 정보는 다음 목적으로만 사용됩니다:

  • 시간 추적: 웹사이트별 사용 시간을 정확하게 추적하고 기록
  • 통계 생성: 일일, 주간, 월간 사용 통계 및 인사이트 제공
  • 시간 제한 기능: 사용자가 설정한 시간 제한을 모니터링하고 알림 제공
  • 서비스 개선: 확장 프로그램의 기능 및 성능 개선

4. 데이터 저장 및 보안

4.1 저장 위치

모든 데이터는 Chrome의 chrome.storage.local API를 사용하여 사용자의 기기에만 로컬로 저장됩니다. 데이터는 다음 위치에 저장됩니다:

  • Chrome 브라우저의 로컬 저장소 (사용자 기기 내부)
  • 외부 서버나 클라우드 저장소에 저장되지 않음

4.2 데이터 보안

  • 모든 데이터는 사용자의 기기에만 저장되며, 네트워크를 통해 전송되지 않습니다
  • Chrome의 기본 보안 정책에 따라 데이터가 보호됩니다
  • 확장 프로그램을 제거하면 모든 데이터가 자동으로 삭제됩니다

4.3 데이터 보관 기간

데이터는 사용자가 명시적으로 삭제하거나 확장 프로그램을 제거할 때까지 보관됩니다. 저장 공간이 부족한 경우 (10MB 초과), 가장 오래된 데이터부터 자동으로 삭제됩니다.

5. 데이터 공유 및 제3자 제공

중요: Tab Timer는 사용자의 데이터를 제3자와 공유하지 않습니다.

  • 데이터는 외부 서버로 전송되지 않습니다
  • 분석 서비스나 광고 네트워크와 데이터를 공유하지 않습니다
  • 법적 요구사항이 있는 경우를 제외하고는 데이터를 제공하지 않습니다

6. 광고

현재 Tab Timer는 광고를 표시하지 않습니다. 향후 광고 기능을 추가하는 경우, 이 개인정보 처리방침을 업데이트하여 사용자에게 알리겠습니다.

광고가 추가되더라도 사용자의 브라우징 데이터는 광고주나 광고 네트워크와 공유되지 않습니다.

7. 사용자의 권리

사용자는 다음 권리를 가집니다:

  • 접근 권리: 저장된 모든 데이터에 접근할 수 있습니다 (확장 프로그램 내에서 확인 가능)
  • 삭제 권리: 언제든지 데이터를 삭제할 수 있습니다 (설정 > 데이터 초기화)
  • 내보내기 권리: 데이터를 JSON 파일로 내보낼 수 있습니다
  • 수집 거부 권리: 확장 프로그램을 제거하여 데이터 수집을 중단할 수 있습니다

8. 권한 사용

Tab Timer는 다음 권한을 사용합니다:

  • storage: 사용 시간 데이터를 로컬에 저장
  • tabs: 현재 활성 탭의 URL을 확인하여 시간 추적
  • activeTab: 현재 탭의 도메인 정보 확인
  • notifications: 시간 제한 도달 시 알림 표시
  • <all_urls>: 모든 웹사이트의 사용 시간 추적

이러한 권한은 위에 명시된 목적으로만 사용되며, 다른 용도로는 사용되지 않습니다.

9. 아동의 개인정보 보호

Tab Timer는 13세 미만의 아동을 대상으로 하지 않으며, 의도적으로 아동의 개인정보를 수집하지 않습니다.

10. 개인정보 처리방침 변경

본 개인정보 처리방침은 법률, 규정 또는 서비스 변경에 따라 업데이트될 수 있습니다. 중요한 변경사항이 있는 경우, 확장 프로그램 업데이트를 통해 사용자에게 알리겠습니다.

변경사항은 이 페이지에 게시되며, 최종 업데이트 날짜가 상단에 표시됩니다.
