# Tab Timer

웹 브라우저에서 각 사이트별 사용 시간을 추적하고 관리할 수 있는 Chrome 확장 프로그램입니다.

## 주요 기능

- 🕒 실시간 사용 시간 추적
- ⏰ 사이트별 시간 제한 설정
- 🔔 시간 제한 도달 시 알림
- 📊 일일 사용 통계 확인
- 🌐 모든 웹사이트 지원

## 기술 스택

- Chrome Extension API
- JavaScript (ES6+)
- HTML5 & CSS3
- Local Storage
- Chart.js (데이터 시각화)

## 주요 기능 설명

### 시간 추적
- 모든 웹사이트의 사용 시간을 자동으로 추적
- 실시간 사용 시간 확인 가능

### 시간 제한 설정
- 특정 사이트에 대한 시간 제한 설정 가능
- 시간 제한 도달 시 알림 제공
- 연장 또는 닫기 옵션 제공

### 대시보드
- 일일/주간 사용 통계 제공
- 상위 사용 사이트 분석
- 시간대별 사용 패턴 시각화
- 생산성 점수 및 목표 달성률 표시

## 개인정보 보호

- 모든 데이터는 사용자의 로컬 기기에만 저장
- 외부 서버로의 데이터 전송 없음
- 오프라인 작동 지원

## 설치 방법

1. Chrome 웹 스토어에서 "Tab Timer" 검색
2. "Chrome에 추가" 버튼 클릭
3. 설치 완료 후 Chrome 툴바에서 Tab Timer 아이콘 확인
